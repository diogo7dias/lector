Today, Look opened + becomes −

Moving onto a section opens it and closes the one before. The first Back collapses it, the second leaves the menu.

  • The selected row fills black edge to edge, square corners (InvertFill, radius 0).
  • The black heading band only covers its own label; it does not run the full width.

Tab strip structure

Real tabs across the top. The book block shrinks to one line and a progress hairline.

  • Every tab is one press away. Back leaves at once, no collapse step.
  • › marks rows that open a screen, so toggles and screens look different.
  • Left/Right are Next/Previous today. This screen would need to claim them.

Bottom sheet structure

The menu covers only the lower half, so the page stays in view above it.

  • Paperback and status bar changes show on the page straight away.
  • Only the sheet redraws, so opening it can be a partial refresh.
  • Paragraph numbers change the layout, so they still apply on close.

Contents page row style

No black bands. It reads like a book's contents page: roman numerals, dot leaders, and a ▸ for the cursor.

  • Almost no solid black, so less ghosting and cheaper partial refreshes.
  • Feels like part of the book rather than a settings app.
  • The cursor is quieter than an inverted row. It needs an eye test on the X3.

Dashboard structure

The four things you do most become buttons at the top. Each section is one row with a summary line.

  • Bookmark, look up and quote take one press from the menu.
  • The chapter scrubber shows where you are in the chapter.
  • Look moves one level down, so a toggle costs one press more than today.
