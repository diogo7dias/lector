# Lector 0.34.0

## New

- Three Korean font families to download: Pretendard, RIDIBatang and MaruBuri.
- The OPDS server picker has an Add Server row.
- Holding Left or Right in dictionary word selection keeps moving through words.

## Fixed

- A book no longer loses its styles for good after being opened when memory was short. The styles are rebuilt the next time there is room. The first open of each book after updating rebuilds its layout once.
- X4 Pro: sleep wallpapers and covers show both mid greys instead of merging them into one.
- XTC books with grey pages keep their grey levels in the cover. Delete a book's cache to redo a cover saved before this release.
- X4 Pro: the SD card is switched off before deep sleep.
