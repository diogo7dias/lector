# Lector 0.31.8

## Faster lists and a cleaner X4 Pro settings screen

X4 Pro Settings and Text Settings now use a full-width, one-column list instead of square cells. Long labels wrap instead of being truncated.

Double-tap the list Up or Down control within 280 ms to move five rows, while a single press still moves one row. This applies to settings, image and file lists, Home, status and OPDS lists, the in-book menu, and button bindings. Holds and swipes keep their existing behaviour.

Page readers, image viewers, dictionaries, sliders, and keyboards keep their existing navigation.

## Verification

The host suite passes 1325/1325 tests. Firmware builds run in GitHub Actions for both X3/X4 and X4 Pro when this release tag is published.

Hardware verification remains recommended for e-ink timing, touch hit areas, orientation, sleep/wake, and cache reuse.
