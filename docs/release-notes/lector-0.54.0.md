# Lector 0.54.0

No book re-indexes. Nothing changes on the X3 and X4.

## New

- **X4 Pro: Fast Page Turns trial.** A new row on the main Settings page, off by default. It opens a page with the switch, how to test it, what to look for and what to report. It uses a quicker page-turn waveform that has not been measured on this panel yet, so it may leave more ink behind. Turn it off if it looks wrong. It changes nothing on X4 Pro units with a UC8279 panel.
