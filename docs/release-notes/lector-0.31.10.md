## Changed

- The X4 Pro's lock screen now lays its wallpaper down on a fully cleared
  panel, the way the X3 already did, so blacks go deeper and the previous
  screen no longer shows through the picture. The trade is that locking
  flashes a few more times before it settles. If you prefer the old quiet
  lock, say so and it goes back.

## Faster

- Finishing a firmware update no longer parks you on the "done" screen for
  four seconds. It now holds just long enough to read, then restarts.
- Paging backwards is now as prepared as paging forwards. The reader loads
  the characters for the page you are heading toward instead of always
  assuming you are moving on.

## Fixed

- A very long chapter no longer freezes the reader while it lays itself out.
  Buttons keep answering, and the page appears as soon as it is ready.
- Opening a large or unusual image can no longer crash the device when
  memory is tight. It now fails the picture instead of the reader.
