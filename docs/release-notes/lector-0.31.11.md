## New

- **Your own fonts on the X4 Pro.** Copy any `.ttf` or `.otf` file into a
  folder on the card, `/fonts/YourFont/`, and pick it in the reader's font
  list. Letters are drawn from the font's own outlines as the page is laid
  out, so every size from 8 to 40 works and stays sharp, not just a short
  fixed list. Drop in up to four files for regular, bold, italic and bold
  italic; anything the family is missing quietly falls back to the built-in
  font, so you never get empty boxes mid-sentence. This one is X4 Pro only
  — the X3 and X4 do not have the memory for it.

## Changed

- Number settings, like brightness and margins, now open on their own screen
  with a slider and Cancel and OK buttons, instead of a strip over the list.
  Backing out with Cancel puts the value back where it was, so trying a
  brightness and changing your mind no longer leaves it changed.
  The trade: while dragging in Text Settings you no longer see the page
  behind update live. Tell me if you want that back.

## Fixed

- Unlocking no longer leaves the top of the screen looking paler than the
  rest. The wake now clears the panel properly before painting your
  wallpaper. Unlocking flashes a little more as a result; say the word if
  you prefer the old quieter wake.
- Leaving a book with the Home gesture, or by letting the device sleep, no
  longer leaves that book's font and margins applied to the next book you
  open. Only leaving with Back used to clean up properly.
