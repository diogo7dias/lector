# Lector 0.65.0

## Changed

- **Wi-Fi and OPDS passwords are no longer left on the card.** The shared sign-in bundle is kept out of reach.
- **The Home key works over the light panel.** It goes Home, as it does everywhere else.

## Faster

- **Chapters open faster on books with printed page numbers.**
- **Sortes is faster.** Back from Sortes opens the book Home already drew.
- **The firmware is about 14 KB smaller.**

## Fixed

- **Fewer crashes and hangs.**
- **Broken books and images are refused** instead of crashing the reader or showing empty pages.
- **Swipes no longer leave a stuck outline** on a list row.
- **KOReader sync frees memory after an upload**, so the reader stays stable afterwards.
- **Nearby Reader opens after a cancelled Join Network** instead of restarting the reader.
