# Lector 0.64.0

## Changed

- **Back always returns to the screen you came from.** Press Back on a screen and you land on the screen that opened it, on the same row. Text Settings, the chapter list, Bookmarks and the other screens opened from the reader menu come back to the menu, not to the page. Book Info comes back to the file actions, Settings > File Transfer comes back to Settings on its card, and the Quick Panel comes back after Reader Settings, or after Settings outside a book (in a book, Back from Settings goes to the page). Choosing something (a chapter, a bookmark, a Yes) still takes you where it did before. The Home key and the Home swipe still go Home.
- **Back also lands in the right place after a restart.** Screens that use Wi-Fi or USB Drive restart the reader when you leave them, to give the memory back. After that restart you now land where Back would have taken you, such as the File Transfer list, the OPDS server you picked or KOReader Settings, instead of Home or the first Settings card.
- **The menus are in English only.** The other menu languages were incomplete and many words did not fit their buttons, so they are gone for now, along with the Language row in Settings. A device set to another language starts in English and keeps all its other settings. Books in any language still open and read as before. The on-screen keyboard is always QWERTY.

## Smaller

- **The firmware is about 470 KB smaller** now that it carries one menu language and no extra menu font.
