# Lector 0.32.0

## Changed

- Removed the built-in hyphenation feature. EPUB soft hyphens remain supported.
- Reorganised the in-book settings menu: Look, Reader Settings, Status Bar, progress, and reading customisation are immediately accessible.
- Nearby Sync is now the first device action in the menu.
- Existing section layout caches are rebuilt once after updating. Books and reading progress on the SD card are preserved.

## Fixed

- Removed unused hyphenation data and layout code, reducing firmware size.
- Removed redundant menu headings and subheadings for a shorter, clearer menu.
