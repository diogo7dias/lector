# Lector 0.61.0

## Changed

- **Show Reader Menu only turns the centre tap on or off.** The swipe up from the bottom edge opens the reader menu inside a book whatever this setting says.

## Fixed

- **A swipe up from the bottom edge opens the reader menu inside a book again,** in EPUB, TXT and XTC books, as a quick flick or a slow pull. Outside a book the same swipe still goes Home, and the Home key below the screen goes Home everywhere, books included.
